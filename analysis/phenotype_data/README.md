# Phenotype Data
This directory contains analysis of phenotypic data, including tissue and shell [growth](https://github.com/jgmcdonough/CE24_RNA-seq/tree/main/analysis/phenotype_data/growth), [final mass](https://github.com/jgmcdonough/CE24_RNA-seq/blob/main/analysis/phenotype_data/massFinal.ipynb), and [nutrient storage](https://github.com/jgmcdonough/CE24_RNA-seq/tree/main/analysis/phenotype_data/nutrients).

This directory largely does not involve the gene expression data. Rather, it aims to plot the phenotypic data of the sequenced oysters, which is a subset of the larger dataset.
